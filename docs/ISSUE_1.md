# Issue #1：启动窗口尺寸和位置

启动窗口按鼠标所在显示器的逻辑可用区域计算尺寸并居中，最大 1320×860，预留屏幕边距。小可用区域下缩放工作台，避免固定最小内容尺寸被裁切。

macOS 先显示原生加载界面，Flutter 首帧准备好后接管窗口。其余桌面 Runner 由 Dart 设置尺寸后显示。窗口可见后才开始打开数据库和载入账号、插件，并显示加载阶段；初始化失败在窗口内显示原因。

验证包括不同大小和偏移的可用区域、窗口显示先于数据库初始化的顺序、加载及失败界面，以及本机 macOS Debug/Release 构建和独立工作区启动检查。真实多显示器与 Windows/Linux 运行仍待对应环境验证。
